# SIP Growth Calculator

A Flask web app that calculates Systematic Investment Plan (SIP) growth over time and optionally saves subscriber emails to Supabase.

## Features

- Interactive SIP calculator (monthly investment, annual rate, duration)
- Year-by-year growth breakdown
- Email subscription stored in Supabase `subscribers` table
- Graceful fallback when `SUPABASE_KEY` is not set

## Local setup

```bash
python -m venv venv
source venv/bin/activate   # or venv\Scripts\activate on Windows
pip install -r requirements.txt
cp .env.example .env       # add your SUPABASE_KEY
python app.py
```

Open http://127.0.0.1:5000

## Environment variables

| Variable       | Description                          | Default                                      |
|----------------|--------------------------------------|----------------------------------------------|
| `SUPABASE_URL` | Supabase project URL                 | `https://bloeoxrxgtgzsccoscgo.supabase.co`   |
| `SUPABASE_KEY` | Supabase anon/service key            | (empty – demo mode)                          |
| `PORT`         | Local server port                    | `5000`                                       |

## Supabase schema

```sql
create table public.subscribers (
  id bigint generated by default as identity primary key,
  email text unique not null,
  monthly_investment numeric,
  target_years integer,
  created_at timestamptz default now()
);
```
